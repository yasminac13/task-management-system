# Task Management System

A graphical desktop application developed for the PT2026 (Programming Techniques) course to manage project workflows, employee allocations, and task scheduling. 

## Key Features
* **Task & Employee Management:** Models for handling employees and tracking simple versus complex tasks.
* **Data Persistence:** Utilizes Java serialization to save and load project states locally (`project_data.ser`).
* **Graphical User Interface:** Built with Java Swing to provide an intuitive dashboard for assigning tasks and monitoring project progress.
* **Core OOP Design:** Strictly adheres to Object-Oriented Programming principles to ensure a clean, modular business logic layer.

## Technologies Built With
* Java
* Java Swing
* Maven
